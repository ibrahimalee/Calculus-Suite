How it works

Row reduction is shown operation by operation. Eigenvalues are given exactly for small matrices where possible, and decompositions are printed factor by factor.

How the answer is checked

Every decomposition is multiplied back to rebuild the original matrix, and inverses are checked by A·A⁻¹ = I.

Typing your input

  • Entries may be numbers or expressions like pi/2. Up to 8×8.
  • Type rows separated by ; and entries by spaces, for example 2 1 ; 1 2.

Questions

Does it show row operations?

Yes, for inverses, determinants and RREF each row operation is listed with the matrix after it.
