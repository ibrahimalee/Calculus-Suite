How it works

The tool solves ∇f = λ∇g together with the constraint, then ranks the candidates by the value of f. For two variables the level curves and the constraint are drawn.

How the answer is checked

Each candidate is checked to satisfy ∇f = λ∇g and the constraint.

Typing your input

  • Give the constraint as an equation in the Constraint option, for example x^2 + y^2 = 1.

Questions

Does it handle three variables?

Yes, for example optimising x + 2y + 3z on the unit sphere.
