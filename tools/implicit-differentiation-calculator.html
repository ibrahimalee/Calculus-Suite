How it works

Everything is moved to one side, F(x, y) = 0. Differentiating both sides with respect to x, and treating y as a function of x, gives F_x + F_y · y′ = 0, so y′ = −F_x / F_y. The steps show F_x and F_y and the rearrangement.

For the second and third derivatives the tool differentiates y′ again, replacing every y′ that appears by the first result. Give a point as "x, y" (for example 3, 4), or just an x value to get every point of the curve with that x. The plot draws the curve itself as the zero contour of F, with the tangent line.

How the answer is checked

The tool solves the equation numerically for y just to either side of a point on the curve and compares the resulting slope with the formula. If the point you typed is not on the curve, it tells you by how much the two sides differ.

Typing your input

  • Differentiate any expression. Type an equation in x and y (such as x^2 + y^2 = 25) to differentiate it implicitly.
  • Write the equation with a single =, for example x^3 + y^3 = 6xy.
  • If the independent variable is not x, set it in the Variable option; the other letter is the dependent one.
  • Order 1, 2 or 3 is supported for equations.

Questions

What is implicit differentiation?

It finds dy/dx when y is defined by an equation such as x² + y² = 25 rather than by a formula y = f(x). You differentiate both sides with respect to x, using the chain rule on every term that contains y, and solve for dy/dx.

What does it mean when F_y = 0 at my point?

The formula −F_x / F_y has a zero denominator there, so the tangent is vertical or the curve has a singular point (a cusp or a self-crossing). The result says which point is affected.

Can I check my homework answer?

Yes. Type the equation and the point; the slope is given as an exact fraction where possible, together with the tangent line.
