How it works

Boolean expressions are minimised with the Quine–McCluskey method. Graphs are given as weighted edges, and Dijkstra, Kruskal and Prim are run on them.

How the answer is checked

The minimal expression is compared with the original on every row of the truth table; Dijkstra is checked against Bellman–Ford, and Kruskal against Prim.

Typing your input

  • Use and, or, not, xor, -> or the symbols ∧ ∨ ¬.

Questions

How large an expression can it handle?

Up to a dozen or so variables comfortably; the truth table doubles in size with each variable.
