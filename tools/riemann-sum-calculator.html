How it works

The interval is split into n equal parts and the chosen rule is applied; the table repeats it for larger n so the convergence and the order of each rule are visible.

How the answer is checked

The sums are compared with the exact integral where it is known, so you can see the error of each rule.

Typing your input

  • Visualise how left / right / midpoint / trapezoid / Simpson sums converge to the integral.
  • Pick n and the rule in the options; Simpson needs an even n.

Questions

Which rule is most accurate?

For smooth functions Simpson's rule is usually best, then midpoint and trapezoid, then left and right sums. The convergence table shows it for your function.
