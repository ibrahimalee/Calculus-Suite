How it works

Each coefficient is f⁽ⁿ⁾(a)/n!, computed from exact derivatives. The result lists the polynomial and the derivative table, and the plot overlays successive partial sums so you can see where the approximation is good.

The Padé task gives a rational approximation [L/M], which is often far better than the Taylor polynomial of the same size, with its poles listed.

How the answer is checked

The coefficients are compared with numerical derivatives, and the polynomial is checked against the function near the expansion point.

Typing your input

  • Taylor polynomial about a point (Maclaurin series when a = 0).
  • A Maclaurin series is a Taylor series about 0, the default point.
  • Choose the number of terms; the degree is shown with the result.

Questions

What is the difference between Taylor and Maclaurin series?

A Maclaurin series is a Taylor series centred at 0. Set the point to expand anywhere else.

How accurate is the polynomial?

The plot shows the function and the polynomial together, and the result estimates the error near the centre.
