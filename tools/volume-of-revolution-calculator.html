How it works

Intersections are found automatically when you do not give limits. The integral set up for each quantity is shown, then evaluated exactly or numerically.

How the answer is checked

Each value is computed a second way numerically, and curvature is compared with the circle through three nearby points.

Typing your input

  • Applications of integration. Add a second curve g(x) for areas between curves and washers.
  • For area between curves, give the second function in the extra field.

Questions

Disks or shells?

Both are available: revolve about the x-axis for disks and washers, or about the y-axis for shells.
