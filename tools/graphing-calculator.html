How it works

Every letter other than x becomes a slider, so a*sin(b*x) gets sliders for a and b. Intersections between curves are found and listed, and the plot can be saved as an image.

How the answer is checked

Intersections are refined numerically and substituted back into both functions.

Typing your input

  • Plot several functions at once. Every extra letter (a, b, c…) becomes a live slider; intersections are marked automatically.
  • Separate several functions with ;
  • Press play next to a slider to animate it.

Questions

Can I plot more than one function?

Yes, separate them with ; and each gets its own colour and legend entry.
