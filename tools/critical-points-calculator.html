How it works

The tool solves f′(x) = 0 and f″(x) = 0 on the interval you choose, classifies each critical point with the derivative tests, and finds asymptotes from limits. The plot marks every feature it found.

How the answer is checked

Points are substituted back, and sign changes of f′ and f″ are confirmed numerically on both sides of each point.

Typing your input

  • Finds roots, extrema, inflection points, asymptotes, monotonicity and concavity.
  • Set the x-range to look for features in a particular interval.
  • Roots and extrema are found numerically and shown to the precision you choose.

Questions

Are the results exact?

Roots and extrema are found numerically and are accurate to many digits; they are not formal proofs. Exact values are shown when they are recognised.

Does it find inflection points?

Yes, as points where f″ changes sign, with the concavity on each interval.
