How it works

The constraints are put in standard form and solved with the two-phase simplex method using Bland's rule. Shadow prices show how much the optimum changes per unit of each constraint.

How the answer is checked

For small problems every corner point of the feasible region is enumerated and compared with the simplex answer.

Typing your input

  • Start with maximise or minimise, then list the constraints separated by ;

Questions

What if there is no solution?

The tool reports whether the problem is infeasible (no point satisfies the constraints) or unbounded (the objective can grow forever).
