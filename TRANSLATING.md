# Helping with translations

Calculus Suite is available in Spanish, French, Arabic, Urdu and Hindi. The first versions were written without a
native-speaker review, so the most valuable thing you can do is read them and tell us what sounds wrong, stiff or unclear.
You do not need to write code.

## The quickest way: one sentence at a time

In the app, open **Settings → Language**, choose your language, and click **Is a translation wrong? Tell us**. That opens a
form on GitHub. Say where you saw it, what it says now and what it should say.

## Reviewing in bulk

1. Open [`translations-review.csv`](translations-review.csv) in any spreadsheet (Excel, Google Sheets, LibreOffice).
   It has one row per interface string: the English original, the five translations, and empty columns for you.
2. Fill in **Reviewer name** and **Language reviewed**. Where a translation is fine, leave it. Where it is wrong or
   unnatural, write your version in **Corrected text**, and use **Notes** to say why.
3. Send the file back by [opening a translation issue](../../issues/new?template=translation.md) and attaching it, or by
   opening a pull request that edits `js/i18n.js` (interface) and `js/i18n-tools.js` (tool labels and hints).

## What matters most

- **Mathematical terms.** Use the word a teacher in your country would use (for example, derivative, integral, limit,
  eigenvalue). If textbooks disagree between regions, tell us which you picked.
- **Short and clear beats literal.** Buttons and labels are small. A natural short phrase is better than a faithful long one.
- **Right-to-left languages.** Arabic and Urdu mirror the layout, while the mathematics stays left-to-right. Tell us if
  a mixed line (words with a formula inside) reads in the wrong order.
- **Tone.** Friendly and direct, the way you would explain it to a classmate.

## What is not translated yet

The worked steps and explanations the engine writes (for example, “Apply the product rule”) are in English. They are
generated by code and have to be translated rule by rule; that is a larger project, and a good place to help if you are
comfortable with JavaScript. Ask in an issue first and we will point you to the right files.

## For maintainers

`npm run i18n:export` regenerates `translations-review.csv` from the dictionaries. Every string needs all five
translations: `npm test` fails if one is missing, and it also fails if a tool label or hint has no entry in
`js/i18n-tools.js`.
