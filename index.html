01 Ask

Say it the way you’d say it out loud.

There is no query language to learn. The parser is a plain rule-based one that runs on your device, so it is fast, private and never makes anything up. If it can’t understand you, it says so instead of guessing.

02 Checked
SpecimenIntegral · by parts

∫ x · eˣ dx

= (x − 1) eˣ + C

  1. Choose u = x and dv = eˣ dx, so du = dx and v = eˣ.
  2. Apply ∫u dv = uv − ∫v du, giving x eˣ − ∫ eˣ dx.
  3. Finish the remaining integral: x eˣ − eˣ + C.

✓ Verified: differentiating the result gives back x · eˣ.

An answer you can see is right.

Most calculators hand you a result and ask for trust. Here, each tool tests its own answer a second way and tells you what it did.

  • Integrals are differentiated back, or integrated numerically, and compared.
  • Equation roots are substituted into the original equation.
  • Matrix decompositions are multiplied back together to rebuild the input.
  • Differential equations are solved a second time by a numerical method.

When something can’t be verified, or is only approximate, the result says that too, in plain words next to the answer rather than buried in the manual.

    04 Principles

    Built to be used by anyone, anywhere.

    Private by construction

    All the maths runs in a background worker in your browser. There is no server to send anything to. The photo-of-a-page feature downloads its text-recognition model only when you tap the camera button, and processes the picture on your device.

    Works without a connection

    After the first visit the whole app is cached. Install it to a phone or laptop and use it on a train, in an exam hall’s dead zone, or on a bad connection.

    Accessible, on purpose

    Keyboard-operable, screen-reader friendly, audited against WCAG 2 A and AA. Results can be read aloud, plots can be described in words, and answers export as Nemeth Code braille (Unicode or BRF) for embossers.

    Honest about its limits

    It is not a computer-algebra giant, and it says so. Some integrals have no closed form here; the translations still need native-speaker review; braille is an automatic transcription. The README lists what to expect.

    05 Open source

    Made to be shared, not rented.

    The code is MIT-licensed and there is no build step: open the folder and it runs. Teachers can embed a worked example in a course page. Developers can use the engine as a library. Everyone can fix a mistake.

    • Teach with itTurn on teaching mode to reveal each step one at a time, or generate practice problems with hints.
    • Embed itAny result has an embed code for a live, interactive copy in your own page.
    • Translate itInterface strings live in one file. Corrections from native speakers are the most useful contribution right now.
    • Improve itBug reports with a failing input are gold. The test suite and contribution guide make a first patch easy.
