Integral, by parts

∫ x · eˣ dx

= (x − 1) eˣ + C

  1. Take u = x and dv = eˣ dx, so du = dx and v = eˣ.
  2. Apply ∫u dv = uv − ∫v du, which gives x eˣ − ∫ eˣ dx.
  3. Finish the remaining integral: x eˣ − eˣ + C.

✓ Checked: differentiating the result gives back x · eˣ.

How the answers are checked

Each tool tests its own answer a second way and says what it did.

  • Integrals are differentiated back, or integrated numerically, and compared.
  • Roots of an equation are substituted into the original equation.
  • Matrix decompositions are multiplied back together to rebuild the input.
  • Differential equations are solved a second time by a numerical method.

When something can’t be verified, or is only approximate, the result says so next to the answer.

    About

    Everything runs in your browser. The maths is done in a background worker and nothing you type goes to a server. The photo-to-text feature downloads its recognition model the first time you use the camera button, and it reads the picture on your device. After your first visit the app is cached, so once it is installed it works offline.

    It can be used from the keyboard and with screen readers, and it has been checked against WCAG 2 A and AA with axe. Results can be read aloud, plots can be described in words, and answers can be exported as Nemeth Code braille.

    It has limits. Some integrals have no closed form here, the translations still need review by native speakers, and the braille is an automatic transcription that a transcriber should check. The README lists what to expect.

    Teachers can build a worksheet, share it as one link and grade the codes students send back, with no accounts and no server. See the teacher tools.

    The code is MIT-licensed, has no build step, and is on GitHub. A bug report with an input that fails is the most useful thing you can send.
