# Code of Conduct

We want this project to be welcoming to students, teachers and developers of every background and level.

* Be kind and patient. Questions about basic maths or code are always welcome.
* Disagree about ideas, not people. Critique code and results, not the contributor.
* No harassment, discrimination, personal attacks or unwelcome sexual attention.
* Do not publish other people's private information.
* Assume good faith, and say so when something is unclear instead of guessing at intent.

Maintainers may edit or remove contributions that break these rules and may block people who repeatedly do so. To report a problem, contact the maintainer through the email listed on the project page; reports are handled privately.
