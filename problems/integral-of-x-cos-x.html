Integral of x cos(x)

∫x⋅cos(x)dx

Answer

∫x⋅cos(x)dx=cos(x)+x⋅sin(x)+C

✓ Checked: the antiderivative was checked by differentiating it at sample points.

Open this in the calculatorIntegral calculator with steps

Step by step

  1. Worked solution (Integration by parts)

    The steps below show one valid technique; every antiderivative agrees up to the constant C.

  2. Integration by parts (round 1)

    Choose u = x and dv = cos(x) dx (LIATE rule). Then du = 1 dx and v = sin(x).

    u=x,dv=cos(x)dx⇒du=1dx,v=sin(x)
  3. Apply ∫u dv = uv − ∫v du

    The remaining integral is ∫ sin(x) dx.

    ∫sin(x)dx
  4. Assemble the result

    F(x) = x * sin(x) + cos(x)

    F(x)=x⋅sin(x)+cos(x)
  5. Add the constant of integration

    Every antiderivative differs by a constant, so we add + C.

    cos(x)+x⋅sin(x)+C
  6. Check by differentiating

    d/dx [ cos(x) + x * sin(x) ] = x * cos(x), which matches the integrand.

    dxd​[cos(x)+x⋅sin(x)]=x⋅cos(x)

About this kind of problem

An antiderivative is a function whose derivative is the one you were given. The working names the technique (table, substitution, by parts or partial fractions) and every answer is differentiated back to confirm it.

For this problem the working uses: Worked solution (Integration by parts), Integration by parts (round 1), Apply ∫u dv = uv − ∫v du, Assemble the result, Add the constant of integration, Check by differentiating.
