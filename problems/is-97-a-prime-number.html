Is 97 a prime number?

is 97 prime?

Answer

97 is prime
  • Next prime: 101

Open this in the calculatorNumber theory calculator

Step by step

  1. Trial division by small primes

    None of 2, 3, 5, 7 divides 97, so 97 has no small factor.

  2. Miller–Rabin set-up

    Write 97 − 1 = 96 as 2^5 · 3, with 3 odd. For a base a, 97 passes if a^3 ≡ 1, or a^(3·2^i) ≡ −1 for some i < 5, (mod 97).

  3. Every base passes

    The first twelve primes (2, 3, 5, …, 37) as bases all pass. This set is proven sufficient for every number below 3.3·10²⁴, so 97 is prime.

About this kind of problem

Large integers are factored with trial division and Pollard’s rho, and primality is tested with Miller–Rabin. Every factorisation is multiplied back to confirm it.

For this problem the working uses: Trial division by small primes, Miller–Rabin set-up, Every base passes.
