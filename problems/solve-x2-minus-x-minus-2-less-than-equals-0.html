Solve x^2-x-2 <= 0

x2−x−2≤0

Answer

x2−x−2≤0;⟺;x∈[−1,2]
  • Critical points: x = -1, x = 2

Open this in the calculatorEquation and inequality solver

Step by step

  1. Move everything to one side

    f(x) = x ^ 2 - x - 2 <= 0

    f(x)=x2−x−2
  2. Find where f changes sign

    Roots and poles split the line into intervals: -1, 2.

  3. Test each interval

    Evaluate f at one point in every interval and keep those with the right sign.

About this kind of problem

Polynomial equations are factored and solved exactly (with complex roots where needed); other equations are solved numerically on a range. Every root is substituted back into the original equation, and inequalities are tested interval by interval.

For this problem the working uses: Move everything to one side, Find where f changes sign, Test each interval.
