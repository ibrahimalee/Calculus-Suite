Solve the differential equation y′ = 3·y-6

y′=3⋅y−6

Answer

General solution: y = 2 + C * exp(3 * x)
Particular solution: y = 2 - exp(3 * x)
  • General solution: y = 2 + C * exp(3 * x)
  • Particular solution: y = 2 - exp(3 * x)

Step by step

  1. Recognise a linear first-order ODE

    Write it as y′ + P(x)·y = Q(x) with P = -3, Q = -6.

    y′+(−3)y=−6
  2. Integrating factor

    μ(x) = exp(∫P dx) = exp(-(3 * x))

    μ(x)=e∫Pdx=exp(−(3⋅x))
  3. Multiply and integrate

    (μ·y)′ = μ·Q, so μ·y = ∫ -(6 * exp(-(3 * x))) dx = 2 * exp(-3 * x) + C

    μy=∫−(6⋅exp(−(3⋅x)))dx=2⋅exp(−3⋅x)+C
  4. Solve for y

    y = 2 + C * exp(3 * x)

    y=2+C⋅exp(3⋅x)
  5. Apply the initial condition

    y(0) = 1 gives C = -1.

    C=−1
  6. Solution values

    y(0) ≈ 1 y(0.75) ≈ -7.487736 y(1.5) ≈ -88.017131 y(2.25) ≈ -852.058738 y(3) ≈ -8101.083942

About this kind of problem
