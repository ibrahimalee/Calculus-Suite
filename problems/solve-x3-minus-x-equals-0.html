Solve x^3-x = 0

x3−x=0

Answer

x=−1,;x=0,;x=1
  • x ≈ -1 residual 0.0e+0
  • x ≈ 0 residual 0.0e+0
  • x ≈ 1 residual 0.0e+0

Open this in the calculatorEquation and inequality solver

Step by step

  1. Polynomial root finding

    All 3 complex roots are found simultaneously (Aberth iteration) and polished with Newton's method.

  2. Polynomial

    1x^3 - 1x = 0

  3. Check

    f(-1) = 0.0e+0; f(0) = 0.0e+0; f(1) = 0.0e+0

About this kind of problem

Polynomial equations are factored and solved exactly (with complex roots where needed); other equations are solved numerically on a range. Every root is substituted back into the original equation, and inequalities are tested interval by interval.

For this problem the working uses: Polynomial root finding, Polynomial, Check.
